# Домашнее задание 2 — Игра «Камень, ножницы, бумага» на Vite

## Возможности проекта

1. матч против компьютера до 3х побед с сохранением прогресса и сбросом при повреждении данных
2. поле ввода имени игрока, которое не теряет фокус и введённый текст во время игры
3. список истории раундов
4. эффект конфетти при победе

## Команды запуска

```bash
npm ci           # установка зафиксированных зависимостей
npm run dev      # запуск dev-сервера Vite
npm run build    # production-сборка в папку dist/
npm run preview  # предпросмотр собранного приложения
npm run lint     # проверка кода линтером ESLint
npm run format   # форматирование кода через Prettier
npm test         # запуск тестов правил игры в Node.js
```
