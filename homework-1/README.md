# ДЗ №1 игра "Камень, ножницы, бумага"

# Правила игры
Матч против компьютера до 3х побед

## Управление
- *Мышь:* клик по карточкам выбора жеста и кнопке «Новая партия».
- *Клавиатура:*
  - `1` или `R` — Камень
  - `2` или `S` — Ножницы
  - `3` или `P` — Бумага
  - `N` — Новая партия
  - `Tab` + `Enter` / `Space` — навигация по кнопкам
